# blog-assets

크림피클(Cream)님의 구글 블로그(Blogger)에 넣는 이미지를 올려 두는 공개 저장소입니다.

- 게시 주소: https://ccreamkiss-design.github.io/blog-assets/
- 이미지는 `images/` 폴더에 두고, 올린 뒤 아래 형식의 주소로 블로그에 넣습니다.

```
https://ccreamkiss-design.github.io/blog-assets/images/파일이름.png
```

- 이 저장소에는 이미지 파일만 올립니다. 개인정보가 담긴 사진, 문서, 비밀번호 등은 올리지 않습니다.
